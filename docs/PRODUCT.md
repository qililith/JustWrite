# 产品与交互

## 普通布局

- 左侧栏，上短下文：上部文档列表（可折叠），下部长目录占满剩余高度。
- 侧栏可收起：正文左上角按钮或 `Ctrl+\` 切换，状态记在本机（`localStorage`），下次打开保持。收起后正文占满宽度；无干扰全屏照常隐藏一切。
- 右侧连续正文，无分页。
- 底栏：字数；侧栏底部：登录 / 同步状态。
- 右上角一个克制的全屏按钮。

## 文档

- 新建：立即出现一篇「未命名」，进入编辑。
- 标题：列表内单击已选中项可重命名；若标题为空，取首个 H1，否则「未命名」。
- 删除：需确认。软删除，列表中消失。
- 切换：点击列表项；`lastOpenId` 在刷新后恢复。
- 自动保存：内容变更后 400ms 防抖写入 IndexedDB。

## 选区工具条

选中文字后出现悬浮胶囊：

`正文` `H1` `H2` `H3` `H4` `H5` `|` `B` `高亮`

- 正文 / H1–H5：把当前选区覆盖的块转成 paragraph 或对应 heading。
- 多块选中：每一块都转换。
- 加粗、高亮：toggle mark，只作用于选中文字。
- 快捷键：`Ctrl+B`；`Ctrl+Alt+1..5`；`Ctrl+Alt+0` 回正文。

## 长目录

- 仅 heading 入目录，按 `level` 嵌套。
- 折叠 / 展开、虚拟滚动、标题过长省略（悬停显示全文）。
- 顶部过滤框：按标题文本过滤（属于目录好用性，不是新功能）。
- 点击：平滑滚动到对应标题并聚焦编辑器。
- 当前节：由滚动位置与光标共同决定，左侧细条 + 浅底。
- 空态：「添加标题后生成目录」。
- 项悬停显示「聚焦」。

## 章节聚焦

- 范围：该 heading 起到下一个同级或更高级 heading 之前（含其间更低级标题）。
- 范围外节点用视图隐藏，文档 JSON 不变。
- 入口：目录项「聚焦」、标题左侧悬停「聚焦」。
- 退出：顶栏「退出」、`Esc`（若未开工具条）。
- 顶栏文案：「正在聚焦：{标题}」。
- 聚焦时字数改为本节。

## 无干扰全屏

进入：右上角按钮、`Ctrl+.`、`F11`。同时加 `is-zen`、请求 `requestFullscreen()`、藏侧栏与底栏。Fullscreen API 不可用时仍进入 zen。

屏上规则：

- 默认无常驻按钮、无字数、无同步状态。
- 鼠标静止约 2 秒隐藏光标。
- 正文约 680px 居中，行距略增。
- 选区气泡仍可用。

热区（未悬停时不可见）：

- 顶 16px：淡入「退出全屏」；若在章节聚焦则同时有「退出聚焦」。
- 左 12px：临时目录浮层，移开后收起。
- 底 16px：字数。

退出与 `Esc`：

1. 选区工具条打开 → 关掉工具条
2. 正在章节聚焦 → 退出聚焦（仍留在全屏）
3. 处于 zen → 退出浏览器全屏并恢复 chrome

监听 `fullscreenchange`：系统退出全屏时必须摘掉 `is-zen`。

## 字数

- CJK 字符各计 1；拉丁按空白分词；标点不计。
- 普通模式底栏「N 字」；全屏只在底热区出现。
- 章节聚焦时为「本节 N 字」。

## 本机文件夹

- 侧栏提供「绑定文件夹」。选择目录后写入 `manifest.json` 与 `docs/{id}.json`。
- 句柄存 IndexedDB。刷新后若权限丢失，提示「重新允许访问文件夹」。
- 不绑定时仅 IndexedDB。其它浏览器可提供单文件下载 / 导入作为退路。

## 账号与同步

- 未登录：完整本地应用。
- 登录 / 注册：极简浮层，邮箱 + 密码。
- 已登录：侧栏底部「已同步 / 同步中 / 离线 / 失败」。
- 退出登录：本地文档保留，停止推云，不清空 IndexedDB。
- 未配置密钥：入口提示「未配置云同步」，不打断写作。
